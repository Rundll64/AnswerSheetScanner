# 智能答题卡扫描阅卷系统 (Smart OMR Answer Sheet Scanner)

一款专为学校、教师及考务人员设计的**纯本地离线标准化答题卡扫描阅卷 Android 应用程序**。内置完整的机器视觉 OMR 识别引擎，无需依赖网络云端或专业大型阅卷机，直接通过手机/平板相机即可实现毫秒级自动评分、成绩在线统计、XLSX 导出与标准化答题卡定制生成。

说明：本程序使用Google Antigravity协助编写，编者其实并不是太懂  qAq
---

## 🌟 核心特色与功能

### 1. 纯本地离线高效阅卷（100% 隐私与数据安全）
- **零网络依赖**：全部图像处理、透视矫正、填涂分析及统计存储均在设备本地完成。
- **项目化考务管理**：支持多场考试独立建档、自定义选择题数量（1~50题）、批量分值设置与教师标准样卷扫码自动填答。

### 2. 中高考考务级红盲光学过滤（Red-Dropout Filter）
- **专色红盲滤除**：采用中高考专业光学阅读机红盲算法，自动将标准答题卡的考务红框（Pantone 185C）、红色选项 `[A][B][C][D]` 及准考证号红线完全滤除为纯白背景。
- **杜绝误报黄框**：石墨 2B 铅笔与红框在物理光谱层面上彻底分离，未填涂选项黑度严格归零（0.00%），彻底解决由于印刷框线造成的误识别与黄框预警。

### 3. 四角自适应定位校正与确认（Interactive 4-Corner Alignment）
- **抗干扰四角寻标**：内置实心黑块与留白边框的反差核测定算法，强力免疫平板反光、屏幕边缘图标与背景杂斑。
- **手势拖拽 + 像素级方向微调盘**：拍照或选图后进入全屏校对界面，可直接用手指拖拽四角定位锚点，或使用 `[⬅️左] [⬆️上] [⬇️下] [➡️右]` 像素级方向键微调准心，确认对齐后一键极速阅卷。
- **局部自适应质心搜索**：吸收拍摄角度倾斜与镜头桶形畸变（±8px），保障 100% 满分判分精准度。

### 4. 标准化答题卡按需定制与生成（Word / PDF）
- **版式自适应缩进**：题目少时自动减少占用高度，为非选择题（解答题）预留充足书写作答空间。
- **大字号粗体选项**：选项框内部明确采用大字号粗体 `[A]` `[B]` `[C]` `[D]`，排版规范醒目，学生填涂目标更精准。
- **多格式导出**：一键生成可编辑的 Microsoft Word (`.docx`) 文档以及国际标准 A4 尺寸矢量排版 PDF，支持 5 题分组与多道解答题自定义。

### 5. 在线成绩表格总览与 XLSX 导出
- **全屏数据看板**：在手机上直接查看类似 Excel 的在线成绩网格，支持考号模糊搜索、分数段排序与快捷筛选。
- **XLSX 格式分享**：一键导出包含考号、总分、客观题得分、主观题加分、各小题作答明细的格式化 `.xlsx` 电子表格。
- **成绩随时修改与作废**：支持对单条成绩进行考号核对、作答修改、主观题加分以及物理删除。

## 🛠️ 技术栈与架构

- **语言与架构**：Kotlin, Android Jetpack
- **界面层**：Jetpack Compose (Material Design 3)
- **相机模块**：CameraX (支持连续取景、高保真拍照与相册选择)
- **算法核心**：
  - 积分图加速的 Bradley-Roth 局部自适应二值化
  - 8自由度单应性矩阵（Homography）高斯消元求解与双线性插值正射透视校正
  - 红盲色度空间滤镜与气泡局部自适应质心峰值寻优算法
- **文档引擎**：纯 Kotlin 实现的标准 OpenXML Word (`.docx`) 与 Android 矢量 `PdfDocument` 渲染器

## 🚀 构建与编译

本项目完全支持使用标准 Gradle 构建工具链编译：

```bash
# 切换至工程根目录
cd AnswerSheetScannerApp

# 编译生成 Release / Debug 安装包
./gradlew assembleDebug
```

编译输出的 APK 位于：
`app/build/outputs/apk/debug/app-debug.apk`
