# 本地 Android 答题卡扫描阅卷系统 — 现代项目化管理版指南

本项目是一个**纯本地离线运行的 Android 智能答题卡扫描阅卷与项目化管理系统**（支持项目化分场考试管理、自由输入数字自定义题数、数据安全存证防删除、四角定位校正、8位考号识别、原图红绿框批改、Excel CSV 一键导出）。

---

## 一、 最新核心功能升级特性

1. **项目化考试分场管理与二级深度跳转**：
   - **一级页面（项目管理中心）**：支持创建多个考试项目（如语文周测、期中物理等），集中查看各项目总人数、均分及安全存证锁状态，一键切换当前激活的阅卷通道。
   - **二级页面（深度统计与导出）**：点击任意考试项目，平滑跳转进入该考试专属看板，包含**参试人数、平均分、最高/最低分、及格率**四大仪表板，以及**各题得分率诊断**与**学生成绩花名册**。

2. **题数自由数字输入与动态分值**：
   - 彻底摆脱固定滑块限制，支持在文本框内直接**输入数字（1~50题）**自定义题量。
   - 附带 10题、20题、30题、40题、50题 快速预设胶囊。
   - 支持批量设置每题满分值，以及从教师样卷一键拍照提取标准答案。

3. **数据存证安全机制（录入数据禁止删除）**：
   - 所有扫码判分录入的学生成绩与作答轨迹永久本地持久化存证，从系统层面上严格杜绝删除操作。
   - 提供**核验与管理功能**：支持在花名册中点击任意考生查看其全题项作答明细（正确/错误/漏涂），支持人工核验调整主观题得分并附加教师备注。

4. **现代 Material 3 视觉与图标交互**：
   - 采用深宝蓝（Royal Blue）与翡翠绿（Emerald Green）现代学术科技配色。
   - 采用圆角卡片、柔和阴影、状态微章胶囊（Status Badges）与全套 Material 3 矢量图标。
   - 取景器升级为翡翠绿雷达对齐框，提示更清晰、对位更精准。

## 二、 编译产物与快速安装

安装包 APK 已经编译就绪：
- **快捷安装文件**：`D:\gemini workplace\答题卡\本地答题卡扫描阅卷_v1.0.0.apk`
- **源码工程位置**：`D:\gemini workplace\答题卡\Android答题卡扫描App完整源码包\AnswerSheetScannerApp`
- **构建环境目录**：`D:\AndroidEnv`（包含独立 OpenJDK 17、Android SDK 34、Gradle 8.4）

直接将 `本地答题卡扫描阅卷_v1.0.0.apk` 复制或微信发送至 Android 手机即可一键安装使用！
